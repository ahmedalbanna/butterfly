USAGE EXAMPLES

Using Helper Script (Recommended):
  ./docker/scripts/start.sh                      # Core only
  ./docker/scripts/start.sh --profile ai         # With AI
  ./docker/scripts/start.sh --profile monitoring # With monitoring
  ./docker/scripts/start.sh --all                # All services

Using Docker Compose Directly:
  docker compose -f docker/docker-compose.yml up -d
  docker compose -f docker/docker-compose.yml --profile ai up -d
  docker compose -f docker/docker-compose.yml --profile '*' up -d

Health Checks:
  ./docker/scripts/health-check.sh               # Check once
  ./docker/scripts/health-check.sh --watch       # Watch continuously
